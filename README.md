## Projects

- [DailyBibleReadings](https://github.com/petealeon/DailyBibleReadings) — a Daily Catholic readings widget for [Omarchy](https://omarchy.org), with matching USCCB podcast playback and a liturgical calendar. Written in QML/Quickshell.

- [thinkpad-fingerprint-omarchy](https://github.com/petealeon/thinkpad-fingerprint-omarchy) — fix the Synaptics/Validity `06cb:009a` fingerprint reader on a ThinkPad T480s under [Omarchy](https://omarchy.org)/Arch, wiring it into `sudo`, polkit, the lock screen and SDDM via the python-validity + open-fprintd stack. Ships install, revert and diagnose scripts.

I'm working on a few macOS CLI tools, and bits and bobs for Omarchy.
